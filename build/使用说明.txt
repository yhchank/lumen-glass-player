流光 Lumen 1.1.3
Windows 液态玻璃风格本地音乐播放器

■ 启动
双击 Lumen.exe 即可。请勿直接运行 LumenCore.exe。
如果 Windows 显示“未知发布者”，请点击“更多信息 → 仍要运行”。

■ 添加音乐
1. 点击左下角“导入音乐”，选择文件。
2. 点击“导入整个文件夹”批量添加。
3. 或者把音乐文件 / 文件夹直接拖进窗口。

■ 支持格式
MP3 / M4A / M4B / AAC / WAV / FLAC / OGG / OGA / OPUS
封面、标题、艺人、专辑、年份、时长和音质信息会自动读取。

■ 界面
- 内容层（侧栏、正在播放、队列、音乐库、卡片）为不透明表面。
- 玻璃保留给底部播放工具栏、菜单、Toast、导入进度和拖放层。
- 主题固定为青绿 + 淡紫，不随专辑封面改变。
- Canvas 频谱在播放时以 30fps 绘制，暂停后停止。
- 背景为纯色，没有动态渐变或极光。

■ 快捷键
Space          播放 / 暂停
← / →          后退 / 前进 5 秒
Shift + ← / →  降低 / 提高音量
M              静音
N / P          下一首 / 上一首
Ctrl + O       导入音乐
Ctrl + F       搜索
Esc            清空搜索 / 取消焦点

■ 数据位置
默认保存到 %APPDATA%\Lumen。
如果该目录不可写，会自动使用程序目录下的 LumenData 或临时目录。
卸载程序不会删除个人资料库；如需要彻底清理，请手动删除上述目录。

■ 说明
- 所有音乐都在本机读取，不会上传网络。
- 启动器默认传入 --no-sandbox 以兼容部分 Windows 安全策略；应用只加载本地内容。
  如需启用 Chromium 沙箱，请设置环境变量 LUMEN_ENABLE_SANDBOX=1 后启动。
- 文件关联、窗口位置、音量、播放模式与资料库都会自动保存。

更多说明见安装目录中的 README.txt、项目 README.md 或项目主页。
